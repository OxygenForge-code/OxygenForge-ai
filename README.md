# OxygenForgeAI

OxygenForgeAI is a modern Android starter app built with Kotlin, Jetpack Compose, and Material 3.

## What is included
- Compose-based chat screen
- Material 3 theming
- A simple AI-style demo response flow
- Gradle build files for Android Studio

## Package
`com.geniskapi.alpha.oxygenforge.ai`

## Build
On macOS / Linux / WSL:
```bash
chmod +x gradlew
./gradlew assembleDebug
```

On Windows:
- Open the project in Android Studio, or
- Use Git Bash and run `./gradlew assembleDebug`

## Notes
- This is a starter project, ready for expansion into a real AI app.
- Replace the demo reply logic with your real API integration when you are ready.
